# UzDoomMapEditor

A simplified, Hammer-inspired map editor for UZDoom.

The editor is intentionally built around human-friendly concepts such as rooms, doors, stairs, props, enemies and triggers. Doom-specific UDMF details are kept behind the exporter instead of being exposed as the primary editing model.

## Initial target

Version 0.1 will provide:

- Windows desktop editor in C# / .NET 10 / WinForms
- Top-down grid viewport
- Rectangular room drawing
- Room selection, movement and resizing
- PropertyGrid-based room properties
- Player-start and entity placement foundations
- Save/load project format
- UDMF export
- One-click launch/test in UZDoom

The 3D viewport, doors, stairs, lifts, slopes, lights, texture thumbnails and higher-level UZDoom helpers follow after the basic map workflow is proven.

## Design rule

The editor model should not require the user to think in linedefs, sidedefs or sector specials. Those are generated by the UDMF export layer.
